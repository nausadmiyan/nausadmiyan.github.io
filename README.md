# Nausad Miyan — Research Portfolio

A professional academic website showcasing research in **sustainable cementitious materials**, **auxetic composites**, and **machine learning–driven modeling**.  
Built using **Jekyll** and hosted via **GitHub Pages**, it features interactive visuals, publication sliders, and structured sections for research, about, and contact.

---

## 🌐 Website Structure

| Page | Description |
|------|--------------|
| **Home (`index.md`)** | Displays research focus, animated image gallery with embedded publication links, and an auto-sliding “Recent Publications” section. |
| **About (`about.md`)** | Personal introduction with profile photo and academic affiliation. |
| **Research (`research.md`)** | Overview of research areas including multiscale simulation, molecular dynamics, precast design, materials testing, and AI-driven modeling. |
| **Contact (`contact.md`)** | Embedded Google Map and institutional contact details. |

---

## 🧩 Features

- Responsive design with optimized layout for desktop and mobile.
- Dynamic publication slider with DOI-linked papers.
- Animated research gallery with non-cropped full images.
- Custom CSS styling for modern appearance.
- Compatible with **GitHub Pages Jekyll themes**.

---

## ⚙️ Setup & Deployment

To run the site locally:

```bash
git clone https://github.com/nausadmiyan/nausadmiyan.github.io.git
cd nausadmiyan.github.io
bundle install
bundle exec jekyll serve
```


Deployment is automatic — every push to the `main` branch updates the live site:  
🔗 [https://nausadmiyan.github.io](https://nausadmiyan.github.io)
